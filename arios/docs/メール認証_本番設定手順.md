# メール認証・パスワード再設定 — 本番設定手順

このドキュメントは、LIFE LINE GARAGE（ARIOS）の「メール認証」を**本番で有効化する**ための手順です。
コード側の実装は完了しており、**Supabase の設定を切り替えるだけ**で有効になります。

---

## いまの状態（重要）

- コードは **Supabase 標準の signUp フロー** に切り替え済み。
- Supabase の「Confirm email」設定で動作が変わります。

| Confirm email 設定 | 会員登録の動き | 必要なもの |
|---|---|---|
| **OFF（現状）** | 登録したら即ログイン（今までと同じ） | なし |
| **ON（本番で有効化）** | 確認メールを送信。リンクを開くまでログイン不可 | メール配信（Resend 等） |

> ⚠️ **Confirm email を ON にする前に、必ず下記のメール配信（Resend）を設定してください。**
> Supabase 標準のメール送信は「1時間に数通」しか送れず、迷惑メールにも入りやすいため、本番運用には使えません。

---

## 有効化の手順（本番移行時に実施）

### 1. メール配信（Resend）を用意する
1. [Resend](https://resend.com/) でアカウント作成。
2. 送信元ドメイン（例：`arios.example.com`）を登録し、表示される **DNS レコード（SPF / DKIM）** を
   ドメインの管理画面に追加 → Resend 側で「Verified」になるまで待つ。
3. Resend で **SMTP 認証情報**（Host / Port / User / Password）を取得。

### 2. Supabase に Resend を SMTP として設定する
Supabase ダッシュボード → **Authentication → Emails → SMTP Settings**
- Enable Custom SMTP を ON
- Resend の Host / Port / Username / Password を入力
- Sender email（例：`no-reply@arios.example.com`）/ Sender name（例：`LIFE LINE GARAGE`）を設定

### 3. 確認メールを ON にする
Supabase ダッシュボード → **Authentication → Providers → Email**
- **「Confirm email」を ON**
- （任意）パスワード最小文字数などのポリシーもここで設定可能

### 4. URL を登録する（リンクの戻り先）
Supabase ダッシュボード → **Authentication → URL Configuration**
- **Site URL**：本番URL（例：`https://arios.example.com`）
- **Redirect URLs** に以下を追加（本番とプレビュー両方）：
  - `https://arios.example.com/auth/callback`
  - `https://<vercelのプレビューURL>/auth/callback`（必要なら）

### 5.（任意）Vercel 環境変数
- `NEXT_PUBLIC_SITE_URL = https://arios.example.com`
  - 未設定でもリクエストヘッダから自動判定しますが、明示しておくとより確実です。

### 6. メール文面（任意・推奨）
Supabase ダッシュボード → **Authentication → Emails → Templates**
- 「Confirm signup」「Reset password」の件名・本文を日本語に変更しておくと親切。

---

## 動作確認（ON にした後）

1. 新しいメールアドレスで会員登録 → 「確認メールを送りました」画面が出る。
2. 届いたメールのリンクを開く → マイページに入れる。
3. リンクを開く前にログインを試す → 「メールの確認が済んでいません」と表示され、再送ボタンが出る。
4. ログイン画面「パスワードをお忘れですか？」→ メール送信 → リンク →「新しいパスワードの設定」画面 → 変更できる。
